# Página principal - Chrys Hotel

Estructura inicial de la página principal basada en el diseño de Figma.

## Estructura

- `index.html` → estructura de la página.
- `styles.css` → diseño y estilos.
- `script.js` → interacciones.
- `assets/` → imágenes exportadas desde Figma.

## Imágenes necesarias

Exporta desde Figma y coloca estos archivos dentro de `assets/`:

- `logo.png`
- `hero.jpg`
- `suite-presidencial.jpg`
- `habitacion.jpg`

Los nombres deben coincidir exactamente con los utilizados en `index.html`.

## Ejecutar

Puedes abrir `index.html` directamente en el navegador o utilizar Live Server desde Visual Studio Code.
